## `capacity` — Prop 5.6: **corrected**

*Claim.* Irreducible totally real f with span < S are finite up to translation for S < 3.

- true as stated, but the threshold is 4: cover the possible positions of the least root by finitely many intervals [a, a + delta]; each set of roots lies in an interval of length S + delta < 4, of capacity < 1 (Fekete), so S < 4 suffices (Robinson: S > 4 gives infinitely many classes).  The proof's interval [0, 1 + S] is what needs S < 3.
